# Case studies

Two finished reels made with this skill. Use them to calibrate pace, density and how far to take
"use the real product".

## Case 1: a file-sharing web app

**Product:** a static web app that shares files and text between nearby devices over WebRTC. No sign-up,
no server storage. Dark UI, one electric lime accent, a bold grotesque display font.

**Approach:** the reel links the app's own stylesheet and rebuilds its UI inside a laptop and a phone with
the app's real class names (its own-device card, peer cards, share box, inbox, inbox items, toasts). Demo
data is invented (two friendly made-up device names, "sunset.jpg 4.2 MB"), because a live screenshot had
picked up a real device on the network.

| Time | Beat |
|---|---|
| 0-3 s | Hook: a yes-question about the old way of moving files to yourself. Four workaround chips (Fwd: Fwd:, cable, note to self, uploading 3%) get struck out and fall. |
| 3-5.3 s | Reveal: lime circle burst, the mark's arrow snaps in, wordmark rises letter by letter, tagline; the lime collapses into the brand pill. |
| 5.3-10 s | Laptop and phone slide in searching (radar); a dotted link forms; device cards arrive; toasts "... is here"; chips No sign-up / No codes / No PIN. |
| 10-14 s | A tap on Send files; the photo lifts, flies along a lime arc with a comet trail into the laptop's Received panel; Accept is clicked; progress fills on both screens; Save appears. |
| 14-18 s | The phone centres; a note is typed into the share-with-everyone box; Share fires three beams; three devices turn lime "Got it". |
| 18-21 s | Proof: device to device, packets flowing through a pipe, cloud struck out, pills. |
| 21-25 s | CTA: mark with radar rings, "Try <name>.", URL types in a lime pill. |

**Music:** "Upbeat Future Bass - So Easy" (BombinSound, Pixabay). Offset 54.07 s, so the breakdown builds
under the hook and the drop at 57.02 s hits the lime burst at 2.95 s.

**Lessons:** faithful UI needs the product's CSS specificity respected; a flight between devices sells
"transfer" better than any text; a real screenshot can leak real data.

## Case 2: a browser sketchbook app

**Product:** a browser sketchbook with felt-tip shapes, offset/halftone fills, pen, highlighter, taped
pictures, dark mode, export. Light dotted paper, ink black, a highlighter yellow, a hand-lettering font.

**Approach:** the reel loads the app's own renderer module and calls its SVG render function for every
element, then animates the output: stroke subpaths draw one after another at a marker speed, a felt-tip
pen follows each path with `offset-path`, offset fills "print" in after the outline, hand lettering
appears letter by letter, pen strokes reveal through a mask, the photo drops and its torn tape slaps on.
The dark scene is the same drawing through the app's own dark inks. Deliberately light, to contrast with
the dark reel in case 1.

| Time | Beat |
|---|---|
| 0-2.8 s | Hook: a one-line, hand-lettered claim about where ideas start. A wild pink loop round its key word, a highlighter under the payoff word, an arrow pointing at it. |
| 2.8-5 s | Reveal: a giant highlighter stroke sweeps the screen yellow; the mark's squiggle draws; the hand-lettered wordmark lands; the stroke lifts off. |
| 5-10 s | The tool rail and header slide in; Idea → Sketch → Ship? → Launch! draws itself; the rail lights each tool as it's used. |
| 10-12.4 s | The box is selected; the Hand popover switches Steady → Wild; the box redraws each time. |
| 12.4-14.9 s | Pen star and squiggle, highlighter over "Sketch", a taped photo drops in. |
| 14.9-17.3 s | Dark mode in a circle from the mark. |
| 17.3-19.7 s | The export sheet; Download PNG; a file chip. "No account. Saved locally." |
| 19.7-25 s | The highlighter sweeps back; a two-word CTA built on the app's own verb; URL types inside a hand-drawn box. |

**Music:** "Start Somewhere Good" (MMAudio, Pixabay). Offset 53.99 s, so a quieter bar sits under the hook
and the hit at 56.79 s lands on the highlighter sweep at 2.8 s.

**Lessons:** when the product has its own renderer, drive it rather than imitating it; a drawing
sequence can lay itself out in time from stroke lengths; the signature transition (the highlighter
sweep) should bookend the reel.
